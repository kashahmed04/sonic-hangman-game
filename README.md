# Sonic Hangman

A Sonic-themed Hangman game where players choose a category and guess their way through characters, quotes, and shows from the Sonic universe.

## Features

- Three Sonic-themed categories: characters, quotes, and shows
- Randomized answers for each game
- Interactive letter guessing
- Hangman graphics drawn with Canvas
- Background music and sound effects using Howler.js
- Win and loss tracking saved between sessions
- Responsive layout for different screen sizes

## Built With

- TypeScript
- HTML
- CSS
- Canvas
- Howler.js
- Vite

## Project Structure

- `public/audio/` - Background music and sound effects
- `public/images/` - Background image and favicon
- `src/` - TypeScript, styling, and project credits
- `index.html` - Main page structure
